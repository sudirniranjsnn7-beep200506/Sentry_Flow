# FlowSentry Dataset Download Guide

**Created:** 2026-10-11  
**Purpose:** Step-by-step instructions to download ISCX-VPN2016 and CIC-IDS2017 datasets

This guide provides detailed instructions for obtaining the benchmark datasets required for FlowSentry. Follow these steps carefully to ensure proper dataset acquisition and licensing compliance.

---

## Prerequisites

- **Internet connection** with sufficient bandwidth (datasets are large: ~28GB + ~50GB)
- **Disk space**: At least 100GB free in `d:\Sentry_Flow\data\raw\`
- **Time**: Downloads may take several hours depending on your connection speed
- **Academic/Research purpose**: These datasets are typically for academic use only

---

## Dataset 1: ISCX-VPN2016 (VPN-nonVPN Traffic)

### Overview
- **Official Name:** ISCX VPN-nonVPN dataset (ISCXVPN2016)
- **Size:** ~28GB of PCAP data
- **Content:** Regular and VPN-encrypted traffic for 7 application types
- **Applications:** Browsing, Email, Chat, Streaming, File Transfer, VoIP, P2P

### Download Steps

1. **Visit the Official Page**
   - URL: **https://www.unb.ca/cic/datasets/vpn.html**
   - Open this page in your web browser

2. **Read the Dataset Description**
   - The page contains details about traffic types and capture methodology
   - Scroll to the bottom to find the download section

3. **Locate Download Link**
   - Look for a section titled **"Download this dataset"** at the bottom of the page
   - You may need to:
     - Fill out a form with your academic affiliation
     - Agree to terms of use
     - Provide an email address

4. **Download Files**
   The dataset typically includes:
   - **PCAP files** (raw packet captures, ~28GB)
   - **CSV files** (flow features generated by ISCXFlowMeter)
   
   Download options:
   - Full dataset (PCAP + CSV)
   - CSV only (if you only need flow features)

5. **Extract to Project Directory**
   ```powershell
   # Create directory
   mkdir d:\Sentry_Flow\data\raw\ISCX-VPN2016
   
   # Extract downloaded ZIP/archive to this location
   # Example (adjust path to your download):
   Expand-Archive -Path "$env:USERPROFILE\Downloads\ISCXVPN2016.zip" -DestinationPath "d:\Sentry_Flow\data\raw\ISCX-VPN2016"
   ```

6. **Verify Contents**
   Expected structure:
   ```
   data/raw/ISCX-VPN2016/
   ├── TimeBasedFeatures-Dataset-15s-VPN.csv
   ├── TimeBasedFeatures-Dataset-15s-NoVPN.csv
   └── [possibly PCAP files]
   ```

### Citation (REQUIRED)
If using this dataset, cite:

```
Gerard Drapper Gil, Arash Habibi Lashkari, Mohammad Mamun, Ali A. Ghorbani,
"Characterization of Encrypted and VPN Traffic Using Time-Related Features",
In Proceedings of the 2nd International Conference on Information Systems 
Security and Privacy (ICISSP 2016), pages 407-414, Rome, Italy.
```

## Dataset 2: CIC-IDS2017 (Intrusion Detection)

### Overview
- **Official Name:** Intrusion Detection Evaluation Dataset (CIC-IDS2017)
- **Size:** ~50GB total (PCAPs + CSVs)
- **Content:** 5 days of captured traffic (July 3-7, 2017)
- **Labels:** Benign + attack types (DoS, DDoS, Brute Force, Web Attacks, etc.)

### Important Note About This Dataset
⚠️ **CIC-IDS2017 is an intrusion detection dataset with attack/benign labels.**

This dataset may **not** have the application-category labels (Web Browsing, VoIP, Streaming, File Transfer) that FlowSentry requires. This will be verified during **CN-003 (Dataset Inspection)**.

If it lacks usable application labels, you may need to:
- Use only ISCX-VPN2016
- Find alternative datasets
- Document the limitation

### Download Steps

1. **Visit the Official Page**
   - URL: **https://www.unb.ca/cic/datasets/ids-2017.html**
   - Open this page in your web browser

2. **Read the Dataset Description**
   - Review the attack timeline and network configuration
   - Understand what each day contains:
     - **Monday:** Benign traffic only (11GB)
     - **Tuesday-Friday:** Attacks + Normal traffic (7.8-13GB each)

3. **Locate Download Link**
   - Scroll to the bottom section titled **"Download this dataset"**
   - You may need to:
     - Register or provide academic affiliation
     - Agree to licence terms
     - Provide contact information

4. **Choose Download Format**
   Two main options are typically available:
   
   **Option A: Machine Learning CSV files** (Recommended for FlowSentry)
   - File: `MachineLearningCSV.zip` or similar
   - Contains: Pre-extracted flow features (80+ features per flow)
   - Size: Smaller, faster to download
   - **Download this if you only need flow features**

   **Option B: Full PCAPs** (Optional)
   - File: `PCAPs.zip` or similar
   - Contains: Raw packet captures
   - Size: Very large (~50GB)
   - Only needed if you want to re-extract features yourself

5. **Extract to Project Directory**
   ```powershell
   # Create directory
   mkdir d:\Sentry_Flow\data\raw\CIC-IDS2017
   
   # Extract downloaded ZIP
   Expand-Archive -Path "$env:USERPROFILE\Downloads\MachineLearningCSV.zip" -DestinationPath "d:\Sentry_Flow\data\raw\CIC-IDS2017"
   ```

6. **Verify Contents**
   Expected structure (CSV files):
   ```
   data/raw/CIC-IDS2017/
   ├── Monday-WorkingHours.pcap_ISCX.csv
   ├── Tuesday-WorkingHours.pcap_ISCX.csv
   ├── Wednesday-WorkingHours.pcap_ISCX.csv
   ├── Thursday-WorkingHours.pcap_ISCX.csv
   ├── Friday-WorkingHours.pcap_ISCX.csv
   └── [possibly more files by time period]
   ```

### Citation (REQUIRED)
If using this dataset, cite:

```
Iman Sharafaldin, Arash Habibi Lashkari, and Ali A. Ghorbani,
"Toward Generating a New Intrusion Detection Dataset and 
Intrusion Traffic Characterization",
4th International Conference on Information Systems Security 
and Privacy (ICISSP), Portugal, January 2018.
```

## After Downloading

### Step 1: Record Dataset Metadata

Update `data/README.md` with:
- Acquisition date (today)
- Version/date from the dataset page
- Which files you downloaded
- Any special notes

### Step 2: Generate Manifest

Run the ingestion tool:

```powershell
cd d:\Sentry_Flow
.venv\Scripts\python.exe -m preprocessing.ingest
```

**Expected output:**
```
========================================================================
SUCCESS: Dataset ingestion complete (CN-002)
========================================================================
Manifest: d:\Sentry_Flow\data\processed\manifest.json
Files registered: [X files]

Next step: CN-003 (Dataset Inspection)
  Run: python -m preprocessing.inspect
========================================================================
```

### Step 3: Verify Checksums

The manifest file (`data/processed/manifest.json`) will contain SHA-256 checksums for all files. These are automatically computed and can be used to verify file integrity.

### Step 4: Proceed to CN-003

Once datasets are in place and manifest is generated, the agent can proceed with:
- **CN-003:** Dataset Inspection (extracts real column names and labels)
- **Label mapping:** Team decision on which dataset labels map to FlowSentry classes

## Troubleshooting

### Problem: Download link not visible
**Solution:** 
- Try a different browser
- Disable ad blockers
- Contact CIC directly: cic@unb.ca

### Problem: Download requires registration
**Solution:**
- Provide your academic email and affiliation
- Wait for approval (may take hours to days)
- Use VPN if accessing from certain countries

### Problem: Download is very slow
**Solution:**
- Try downloading during off-peak hours
- Use a download manager for resume capability
- Consider alternative sources (Kaggle, academic mirrors)

### Problem: Extracted files don't match expected structure
**Solution:**
- Check if there's a nested directory structure
- Move files to match the expected structure shown above
- Contact me with the actual file listing for guidance

### Problem: Files are corrupted or incomplete
**Solution:**
- Re-download the dataset
- Verify download completed (check file sizes)
- Compare checksums if provided by CIC
