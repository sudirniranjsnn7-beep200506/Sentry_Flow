## Known limitations

**Feature count discrepancy:**
- Dataset has only 24 features per file
- Review-1 mentions "80+" features from CICFlowMeter
- Possible reasons:
  - These are "time-based features" (subset of full CICFlowMeter output)
  - Different time windows (15s, 30s, 60s, 120s) produce different aggregations
  - Full feature set may be in different files not yet uploaded
- **Impact:** Model may have fewer features than originally expected
- **Action:** Document this in training reports; note as limitation

**Empty label instances:**
- 3 rows have empty labels (blank string)
- Mapped to DROP
- Impact: negligible (3 out of 59,707 rows)

**Missing dataset:**
- CIC-IDS2017 not yet uploaded/verified
- Current analysis based only on ISCX-VPN2016
- May add CIC-IDS2017 later if it has usable application labels

**Duplicate rows:**
- Multiple files show duplicate row counts (e.g., 1,257 duplicates in 120s file)
- Will be removed during preprocessing (CN-004)

**Label distribution imbalance:**
- BROWSING: 40,000 instances (67% of kept data)

- **Dropped labels:** CHAT (10,688), MAIL (7,616), P2P (14,830), Scenario A (59,709)
- Streaming is significantly underrepresented
- May need to address class imbalance during training

## Label Mapping Decisions

All mappings documented in `config/label_mapping.yaml`:

**Web Browsing ← BROWSING, VPN-BROWSING**
- Clear match to target class
- Both encrypted and unencrypted variants

**VoIP ← VOIP, VPN-VOIP**
- Clear match to target class
- Includes Skype, Hangouts, etc.

**Streaming ← STREAMING, VPN-STREAMING**
- Clear match to target class
- Video/audio streaming (YouTube, Vimeo)

**File Transfer ← FT, VPN-FT, P2P, VPN-P2P**
- FT = File Transfer (SFTP, FTPS, Skype file transfer)
- P2P mapped to File Transfer (Bittorrent = file sharing)

**DROP ← CHAT, VPN-CHAT, MAIL, VPN-MAIL, VPN, Non-VPN, (empty)**
- CHAT: Not in target classes (instant messaging)
- MAIL: Not in target classes (email)
- VPN/Non-VPN: Encryption labels, not application categories
- (empty): Data quality issue (3 instances)
