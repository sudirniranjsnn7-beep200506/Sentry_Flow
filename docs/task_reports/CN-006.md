## Training Infrastructure Design

**Pipeline Architecture:**
```
Training Data (47,696 samples, 21 features)
    ↓
LabelEncoder (string → integer classes)
    ↓
Pipeline:
  1. Preprocessor (imputer → scaler)
  2. Selector (variance → correlation → importance)
  3. Classifier (DecisionTreeClassifier)
    ↓
GridSearchCV (StratifiedKFold, n_splits=5)
    ↓
Best Pipeline (refitted on full training set)
    ↓
Run Artifacts (saved to disk)
```

**Key Design Choices:**
- **Stratified CV:** Preserves class proportions in each fold (critical for imbalanced data)
- **Macro-F1 scoring:** Treats all classes equally (not biased toward majority class)
- **Selector inside pipeline:** Prevents data leakage (fits separately in each CV fold)
- **Full pipeline saved:** Identical preprocessing for training and inference
- **Seed recorded:** Every random operation is reproducible
- **Complete metadata:** Every run is self-documenting
