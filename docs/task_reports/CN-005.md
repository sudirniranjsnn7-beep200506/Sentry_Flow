## Feature Selector Implementation

**RID-08 Compliance:** ✅ Staged selector implemented

**Selector Architecture:**
```python
Pipeline([
    ('variance_filter', VarianceThreshold),
    ('correlation_filter', CorrelationFilter),  # Custom
    ('importance_selector', SelectFromModel),
])
```

**Key Properties:**
- Fits only on training data (never test)
- Deterministic (with fixed random_state)
- Transparent (logs removed features)
- Configurable (thresholds from config)

**Custom CorrelationFilter:**
- Implements scikit-learn estimator interface
- Finds pairs with |r| > threshold
- Removes one feature from each pair (deterministic)
- Logs which features are removed

- Fits inside cross-validation folds
- Same pipeline used for training and inference
