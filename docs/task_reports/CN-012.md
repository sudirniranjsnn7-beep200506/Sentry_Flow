## Known Limitations

1. **Single Model:** Only Decision Tree registered (other models not trained).

2. **No Versioning:** If same model_id re-registered, it updates the entry. No version history kept.

3. **No Distributed Registry:** File-based, local only. Not designed for multi-machine deployment.

4. **Label Encoder Location:** Label encoder loaded from runs/ directory (not copied into registry). This is acceptable because:
   - Label encoder is small
   - Pipeline contains the main model logic
   - Runs/ directory is part of project artifacts

5. **Git Commit Not Recorded:** env.json doesn't include git commit hash (no git integration implemented). Could be added later if needed.
